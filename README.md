# 💎 Pandora 📦

숨어 있는 보석을 모두 찾는 3D 웹 퍼즐 게임입니다.

## 게임 방법

n×n 그리드의 상자가 모두 뚜껑이 닫혀 있습니다. 상자 안에는 보석이 들어 있거나 비어 있습니다.

**보석 배치 규칙** — 이 규칙으로 보석 위치를 추리할 수 있습니다:

- 각 행에 보석이 정확히 1개
- 각 열에 보석이 정확히 1개
- 같은 색 상자 묶음(연결된 영역)마다 보석이 정확히 1개
- 보석끼리는 대각선을 포함해 서로 붙어 있을 수 없음

모든 판은 논리만으로 풀 수 있도록 **해가 유일한 판만** 생성됩니다.

**조작**

- **드래그**: 그리드를 돌려 봅니다 (마우스 우클릭 드래그도 가능).
- **길게 눌러 드래그**: 검은 ✘ 마킹 (보석이 없다는 추측 표시). 상자를 약 0.4초 누르면 마킹이 시작되고, 그대로 끌면 지나가는 상자에 일괄 적용/해제됩니다.
- **더블클릭**: 상자 열기 — 보석이 있으면 뚜껑이 천천히 열려 빛나는 보석이 드러나고 해당 행/열/주변 8칸이 자동 마킹됩니다. 비어 있으면 상자가 눌려 가라앉으며 독성 연기가 계속 피어오릅니다.
- **핀치 / 휠**: 확대·축소.

빈 상자를 3번 열면 게임 오버입니다. 보석을 모두 찾으면 다음 레벨로 넘어가며, 5×5에서 시작해 최대 12×12까지 커집니다. 진행한 레벨은 자동 저장됩니다.

## 실행

WebGL(Three.js)로 렌더링하며 ES 모듈을 사용합니다. `index.html`을 파일로 직접 열면(`file://`) 브라우저가 모듈 로드를 막으므로, 폴더를 로컬 서버로 띄워서 여세요:

```
python3 -m http.server
```

그런 다음 브라우저에서 `http://localhost:8000` 을 엽니다. Three.js는 `vendor/three.module.js`로 함께 포함되어 있어 별도 빌드나 인터넷 연결이 필요 없습니다.
